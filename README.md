# apognu/fedora-pkgs

Personal Fedora COPR repository: the Hyprland stack, SwayOSD, Zen Browser and
Astal (with every dependency Fedora does not ship).

Targets Fedora 44, x86_64.

```sh
sudo dnf copr enable apognu/fedora-pkgs
```
